# 星图视觉参考提示词（REQ #18）

> 需求来源：《2D转3D与星图需求明细》第 18 条「视觉风格-提示词｜AI 生成参考提示词」（P3）。
> 用途：给 Midjourney / Stable Diffusion 生成星图背景概念图、宣传图或设计方向参考。
> **这些提示词只用于做设计参考图，不参与程序运行。**程序里的星图全部是运行时程序化生成的（见 `src/galaxy/star/`），不加载任何外部图片资源。

---

## 一、主提示词（英文，可直接复制）

### 1. 标准版：深空知识星图

```
A complex 3D knowledge graph visualization floating in deep black space,
glowing nodes acting like stars, connected by thin translucent cyan lines
forming a massive network sphere. Cyberpunk style, high-tech data interface,
holographic projection effect. Nodes emitting blue, orange and white light
with bloom effects. Tiny data text and code fragments floating around.
Cinematic lighting, depth of field, 8k resolution, extremely detailed,
Unreal Engine 5 render style --ar 16:9 --stylize 500
```

### 2. 特写版：单颗发光节点

```
Extreme close-up of a single glowing data node in deep space, a bright cyan
core with soft volumetric glow bleeding into violet, surrounded by dozens of
faint connection filaments trailing off into darkness. Macro depth of field,
bokeh particles, lens flare, cyberpunk holographic aesthetic, black background,
cinematic, ultra detailed, 8k --ar 16:9 --stylize 400
```

### 3. 剖面版：星系与文件层级同构

```
Isometric cutaway of a galaxy where each spiral arm is a folder hierarchy,
inner rings dense with bright nodes, outer arms sparse with dim particles.
Semi-transparent wireframe shells overlaid on nebula clouds, orange accent
lines marking connections, deep blue-black void, HUD data labels floating in
the scene. Sci-fi cockpit interface, Unreal Engine 5, 8k, cinematic lighting
--ar 16:9 --stylize 750
```

### 4. 竖版（手机壁纸 / 启动页）

```
Vertical composition: a luminous knowledge nebula rising from the bottom of
frame into empty black space, glowing filaments converging into a bright core
near the lower third. Minimal, lots of negative space at the top, subtle cyan
and orange highlights, cyberpunk hologram texture, 8k, cinematic
--ar 9:16 --stylize 600
```

## 三、微调建议

### 密集度

| 想要 | 加什么 | 减什么 |
| --- | --- | --- |
| 更密（数据量感） | `dense network`, `thousands of nodes`, `billion数据` 风格的 `massive scale` | 去掉 `minimal`、`negative space` |
| 更疏（干净海报） | `minimalist`, `sparse`, `lots of negative space`, `few dozen nodes` | 去掉 `dense`、`extremely detailed` |

### 干净度

- 想更干净：加 `clean composition`、`uncluttered`，并把 `extremely detailed` 换成 `detailed`；负面提示词加 `--no clutter,noise,glitch,text`。
- 想更脏更真实：加 `film grain`、`chromatic aberration`、`scan lines`。

### 文字处理

**AI 生成的文字基本都是乱码。** 需求表原文就点明了这一点：

- 概念图里不要指望它写对中文：加 `--no text,letters,watermark` 把文字彻底去掉，后期用设计工具贴真实文案。
- 如果一定要有"有文字的感觉"，让它生成**抽象字形占位**（`abstract glyphs`, `illegible micro text`），远看有信息密度，近看不怕放大。

## 四、参数建议

| 参数 | 取值 | 适用 |
| --- | --- | --- |
| `--ar 16:9` | 1920×1080 比例 | 官网首图、PPT 背景、README 配图 |
| `--ar 21:9` | 超宽 | 桌面壁纸、超宽屏启动图 |
| `--ar 9:16` | 竖版 | 手机壁纸、移动端启动页 |
| `--ar 1:1` | 方图 | 应用图标底图、社交头像 |
| `--stylize 250` | 低 | 更写实、更接近真实渲染图 |
| `--stylize 500` | 中（默认推荐） | 平衡质感与艺术性 |
| `--stylize 750` | 高 | 更抽象、更"海报感" |
| `--chaos 0~20` | 低 | 想在一批图里保持统一风格 |
| `--chaos 40+` | 高 | 找设计方向时可以拉开差异 |

Stable Diffusion 侧对应：

- 模型：偏写实的底模 + `cyberpunk`/`sci-fi` LoRA；
- 采样：`DPM++ 2M Karras`、30~40 步；
- CFG：6.5~8（太高会把发光体烤成死白）；
- 负面提示词：`text, watermark, logo, lowres, jpeg artifacts, oversaturated, blown highlights`。

## 五、用的时候注意

1. **概念图只做方向确认**，不要把生成的图直接当运行时素材——图里的光斑是死的，程序里的星图要跟随数据实时布局，静态底图会让"节点位置"和"实际文件"对不上。
2. 想要"和程序里一模一样"的截图，正确做法是运行程序按 `Ctrl+G` 进星图后截屏，而不是让 AI 画。`docs/screenshots/` 里的星图截图都是真机截的。
3. 生成图若用于对外宣传，注意底模与 LoRA 的商用授权。
